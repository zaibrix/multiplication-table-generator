# ✖️ Multiplication Table Generator

A clean and interactive web app that instantly generates a multiplication table for any number. Built using HTML, CSS, and JavaScript, this project helped me practice DOM manipulation, loops, and responsive design — all while keeping the UI modern and user-friendly.

## 🚀 Live Demo

🔗 [Try it here](https://zaibrix-multiplayer.netlify.app)

## 🖼️ Screenshot

![Multiplication Table Preview](./screenshot.PNG)


## ✨ Features

- ✅ Instantly generates a multiplication table for any number
- ✅ Automatically clears previous results before showing new ones
- ✅ Smooth fade-in animation for generated output
- ✅ Scrollable result section for long tables
- ✅ Fully responsive and works on all screen sizes
- ✅ Clean, modern UI with gradient backgrounds

## 🚀 How to Run Locally

1. **Clone this repository:**
```bash
   git clone https://github.com/zaibrix/multiplication-table-generator.git
```

2. **Open the project folder:**
```bash
   cd multiplication-table-generator
```

3. **Open `index.html` in your browser**, or use **Live Server** in VS Code for hot reload.
